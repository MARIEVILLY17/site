1.1 Componentes Internos

1.1.1 CPU

A CPU (Unidade Central de Processamento) é o cérebro do computador, responsável pelo processamento das instruções.

1.1.2 Armazenamento

Dispositivos de armazenamento como HDDs e SSDs são utilizados para guardar dados de forma permanente.

1.1.3 Memória

A memória RAM (Random Access Memory) é a memória de acesso aleatório, que armazena temporariamente os dados e programas que estão a ser usados. A sua função é permitir que o computador execute várias tarefas ao mesmo tempo, como abrir vários programas, navegar na internet, editar planilhas, entre outras

1.1.4 Fonte de Alimentação

A fonte de alimentação converte a energia elétrica da tomada para os componentes internos do computador.

1.2 Componentes Externos

1.2.1 Teclado

O teclado é um periférico de entrada que permite digitar textos e comandos.

1.2.2 Monitor de Vídeo

O monitor exibe informações visuais processadas pelo computador.

1.2.3 Mouse

O mouse é um dispositivo apontador usado para interagir com elementos gráficos na tela.

1.2.4 Impressora

Dispositivo que imprime documentos e imagens em papel.

1.2.5 Plotter

Equipamento utilizado para impressões de grande escala, como plantas arquitetônicas.

1.2.6 Scanner

O scanner digitaliza documentos e imagens para o computador.

1.3 Interfaces de Entrada e Saída

1.3.1 Interfaces Sem Fio

Interfaces como Wi-Fi e Bluetooth permitem a comunicação sem cabos entre dispositivos.

1.3.2 Áudio

Entradas e saídas de áudio permitem a conexão de microfones e caixas de som.

1.3.3 Rede (Ethernet)

A interface Ethernet é usada para conectar computadores à internet via cabo.

1.3.4 VGA

O conector VGA transmite sinais de vídeo analógicos para monitores.

1.3.5 HDMI

A conexão HDMI transmite áudio e vídeo digital em alta qualidade.

1.3.6 USB

A interface USB permite conectar dispositivos periféricos ao computador.

2. Grandezas

2.1 Potência Elétrica

Define a quantidade de energia elétrica consumida ou gerada por um dispositivo.

2.2 Tensão Elétrica

A tensão elétrica, medida em volts, é a força que impulsiona os elétrons em um circuito.

2.3 Corrente Elétrica

Corrente elétrica é o fluxo de elétrons através de um condutor, medida em amperes.
